# VK_IMPACT

Современный, легкий и быстрый кроссплатформенный клиент социальной сети **ВКонтакте** на базе **Python**, **Kivy** и **KivyMD** (Material Design 3).

---

## Особенности архитектуры

- **MVVM + Clean Architecture**: Разделение на Presentation (UI / Screens), Domain (ViewModels / реактивные свойства Kivy) и Data (VK API, SQLite кэш, Long Poll).
- **Неблокирующий UI**: Интеграция `asyncio` и цикла событий Kivy через `asynckivy`. Никаких зависаний при загрузке сети или обработке медиа.
- **Мгновенные сообщения (Real-Time)**: Сервис `VKLongPollService` слушает User Long Poll в фоне.
- **Офлайн-режим (Cache-First)**: Диалоги и история сообщений сохраняются в локальной базе данных SQLite (`aiosqlite`) для мгновенного отображения.
- **Безопасность**: Шифрование токенов доступа с помощью AES/Fernet (`cryptography`).

## Структура проекта

```
VK_IMPACT/
├── src/
│   ├── core/              # Конфигурация, константы, логирование, безопасность, шина событий
│   ├── data/              # Сетевой слой (VK API, Long Poll), SQLite база данных, репозитории
│   ├── domain/            # ViewModels (реактивная бизнес-логика экранов)
│   ├── ui/                # Компоненты интерфейса, экраны (MDScreen) и KV разметка
│   └── utils/             # Асинхронные утилиты, форматтеры дат и текста
├── tests/                 # Модульные тесты архитектурных компонентов
├── main.py                # Точка входа в приложение
└── requirements.txt       # Список зависимостей
```

---

## Запуск приложения

1. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

2. Запуск тестов архитектуры:
   ```bash
   python tests/test_architecture.py
   ```

3. Запуск приложения:
   ```bash
   python main.py
   ```
